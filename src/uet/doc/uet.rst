Ultra Ethernet Transport
------------------------

The UET module provides packet-level models for the mandatory UEC 1.0.3 AI Base profile. It includes
bit-layout PDS and SES codecs, SES transaction execution, RUD/ROD/UUD delivery, PDC lifecycle and
control traffic, NSCC congestion control, trimming recovery, and UDP transport over IPv4 and IPv6.
The examples include deterministic reliability demonstrations and multi-node incast/all-to-all
workloads.

The model is intended for protocol behavior and performance studies, not compliance
certification.
